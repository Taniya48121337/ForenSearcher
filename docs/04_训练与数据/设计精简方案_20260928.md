# 设计精简方案：从 16 个零件收到 7 个（2026-09-28，负责人已拍板）

背景：RSI 方案（09-24）定稿后，方法里有 3 根杠杆、4 条数据通道、3 道门，外加路由器、双干预、课程、内化、自指提议者、手册修剪。负责人认为零件过多，要求给出取舍。**2026-09-28 负责人拍板：全部按本文建议执行**（含删课程通道、双干预只在第 1–3 轮做）。已同步：DESIGN.md §8（标 [09-28]）、RSI 融入方案（顶部修订表）、Demo 论文草稿页 §3.4–3.7 与图 2、总 TodoList 阶段 06–10。

## 判断标准

只留为"别人没测过的量"服务的零件。漏洞审查 §4 定下的三个量：路由先验对反事实最优杠杆的预测准确率、跨角色错误传播的归因准确率、核验分–提升的剂量–反应。三者都长在同一个东西上——逐单元、带角色归因、以外部材料为锚的核验账本。借来的零件（ACE 手册、Agent0 课程、Harness-Zero 内化、Meta-Harness 式自指提议者）每多一个，就多一个"这不就是 X"的攻击面，并且各自需要一组防御机制。

## 精简后的方法

一个逐单元核验账本给出"哪个角色、哪类错误"；一个两问路由先验决定"改规格还是改权重"，并用双干预实测其预测准确率；两个角色用彼此的产出交替训练，教师依赖率逐轮下降。

贡献：（1）核验路由——归因准确率 + 路由预测准确率；（2）双角色伙伴同步训练——协同项；（附）对 Seed 三篇的正面测量——剂量–反应、方向一致率。

## 实验

保留 E1 四臂、E3 2×2、E4 双干预 + 植入缺陷、E5 剂量–反应、E7 迁移。E2 方向一致率从门 A 日志直接统计，不设独立实验。E6 删。结果等于漏洞审查 §9 最小可发表集 + E7。
