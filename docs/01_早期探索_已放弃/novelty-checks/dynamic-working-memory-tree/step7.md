# Step 7 — Delta and Verdict

Timestamp: 2026-08-26 00:32:49 +08:00

## Delta

Unlike ToE and Trification, which organize fact checking around claim/subclaim nodes or fixed verification-action nodes, and unlike TreeSeeker and ReTree, which organize generic search around branch states or per-step memory states, the proposed method makes every model-derived local investigation a complete multi-round Harness-1 workspace with its own search history and budget while reusing a global evidence pool, and learns this workspace-derivation policy for transfer across heterogeneous video-verification tasks.

## Verdict

**Level 2 — High Overlap.** Dynamic trees, claim decomposition, task/action graphs, branch-local search memory, tree-structured working memory and persistent evidence reuse all have direct prior art. No checked paper combines the exact node semantics, edge semantics, Harness execution unit, shared evidence design and unseen video-task transfer objective. Therefore the full combination is not fully scooped, but “using a tree” or even “tree-structured working memory” cannot be claimed as the main novelty.
