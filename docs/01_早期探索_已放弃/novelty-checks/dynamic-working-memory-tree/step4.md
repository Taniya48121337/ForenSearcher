# Step 4 — High-Potential Candidates

Timestamp: 2026-08-26 00:32:49 +08:00

1. **ToE** — same narrow field; dynamic fact-checking tree; per-node retrieval and evidence.
2. **Trification** — same narrow field; dynamically modifiable task/action graph with explicit dependencies.
3. **TreeSeeker** — strongest cross-domain mechanism match; sub-goal trees plus branch-local memory and explicit tree scheduling.
4. **ReTree** — explicitly claims tree-structured working memory for search agents.
5. **MERMAID** — same field and persistent evidence reuse, although memory is not a task tree.
6. **LoCal** — same field and model-generated subtasks delegated to agents, although organized as an iterative sequence.
7. **DEFAME** — multimodal fact-checking with dynamic tool planning and an evolving report, but no tree.

ProgramFC is retained as foundational decomposition prior art but is less threatening than the seven candidates because its program is sequential and its handlers are fixed functions.
