# Zotero Upload Plan

## 02_Core Papers

- Harness-1 — 运行底座与外部工作记忆。
- ToE — 动态 claim/subclaim 证据树，属于最直接竞争工作。
- LATS — 通用 Agent 状态—动作树，用 MCTS 统一控制探索与回溯。
- ToolTree — 面向工具调用轨迹的状态树，以执行前后反馈选择和剪枝。

## 03_Related Work

- Trification — 固定核查动作节点组成的动态依赖图。
- SIGHT — 信息增益驱动的 rollout 动态分支。
- LLM-First Search — 由模型自行决定继续当前路径还是探索其他分支。

## 05_Method Sources

- ReTree — 状态演化树、证据溯源与依赖回滚。
- Explaining Answers with Entailment Trees — 叶子事实、中间结论与根假设的严格树语义。
- Tree of Thoughts — 候选生成、状态评价与通用树搜索基线。
