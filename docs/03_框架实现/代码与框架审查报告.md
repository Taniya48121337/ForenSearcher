## 共享与私有信息

| 信息 | GIA | 每个 HI |
|---|---|---|
| 完整提交的 E、原始 Artifact、来源及派生关系 | 全局可查可读 | 同一调查内共享，包括兄弟 HI 新提交的 E；每次行动前刷新有限卡片视图 |
| 原图、PDF 页面、视频帧 | 通过证据记录及 HI 报告汇总 | 从自己的当前可见材料中选取，直接进入本次多模态请求 |
| 候选来源 R、普通材料 C | 按全局权限访问 | 仅限本工作区已知引用；已提交 E 的来源 R 可沿出处关系读取 |
| Workspace 的任务和运行状态 | 可查询全部工作区 | 只能读取自身任务与状态 |
| Finding 与 Workspace Report | 汇总所有已完成记录 | 仅能读取自身记录，不能读取兄弟判断或报告 |
| 行动历史、焦点、最新 Observation | 自身全局决策历史 | 独立构造请求，仅恢复自身审计记录 |
| 模型参数、API 客户端、累计费用 | 共用 Qwen3.8-27B 与总预算 | 相同模型客户端并发服务各 Workspace，输入分别构造 |
| API Key | 应用配置负责，不进入提示 | 不进入模型上下文、报告或证据 |

“私有”指框架角色访问和上下文隔离。OpenRouter 会将实际请求发送给所选供应商；它不表示输入材料仅存于本机。完整轨迹包含各角色输入和输出，应按调查数据管理。HI 自己对图片的解释保存在局部 Finding/报告中，不自动发布为共享分析 E；OCR、ASR 等工具产物仍按原有协议形成可追溯 E。

Evidence 卡片保持六字段：`evidence_id`、`modalities`、`label`、`source_ref`、`derived_from`、`acquired_by`。页码、时间戳和文件路径位于完整记录及 Artifact 元数据中，多模态请求的附图清单不改变卡片字段。`I0/I1`、E 和 R 编号仅标识导入条目或记录，不证明来源独立、拍摄日期或真实性。

## 多模态输入与恢复

HI 每次最多接收8张图片，交替选取焦点与最新工具观察，再由分配的任务材料补充；共享索引中的其他图片由 HI 按编号选择。保留各组内部顺序并去重，image_input_limit 明示批次容量。图片按 EXIF 方向处理，小图按比例插值放大到长边768像素，所有尺寸调整受150万像素上限约束；插值不增加原图信息，原文件保留。PDF 通过 get_pages 渲染，视频通过 get_frames 或 locate_frames 取得带实际位置的帧；模型不会因为看到视频或 PDF 的卡片而被视为已经看到完整内容。

附图标明 E 编号、来源、派生关系、原位置与输入尺寸。超出批次上限、文件损坏、文件大小或像素超限会在输入中标注；只有请求成功返回后，实际提供的图片才进入已查看集合。附图元数据继续受现有模型视图总大小限制。

每个 HI 可通过 focus_evidence_ids 调整后续批次，并选择取页、取帧、裁剪、OCR 或 ASR。图中清晰文字由 HI 直接理解，精确文字提取可用 OCR。视频抽样不代表整段视频已经连续查看；时序对齐的候选匹配也不等于唯一编辑过程。

成功模型响应的审计事件保存实际附图编号。中断恢复只读取本工作区的事件，失败请求不把图片标为已查看。结构化输出校验失败时，已成功提供的图片状态仍可恢复；供应商在途请求、未返回的隐藏内容和 KV cache 不恢复。

READ_RECORD 中原始媒体和派生图片的描述会标明仅含记录文字或元数据，不代表文件正文或像素已经提供。媒体元数据和空正文页不进入已查看内容集合，恢复时采用同一规则。原图、PDF 原件及渲染页面三个用例均覆盖“未送入像素、读取元数据、尝试引用未读内容”的拒绝路径；实际像素和已读正文仍按原有规则支持引用。

READ_RECORD 的网页正文页附带可访问来源 R 的 source_url/final_url，来源读取同时记入审计；不附带候选检索上下文，不改变六字段卡片或兄弟工作区权限。对齐锚点返回 time_b_minus_a_s（B时间减A时间），与包含采样误差的区间端点分开。

视觉对齐在工具内部执行低分辨率采样、SIFT/FLANN匹配、RANSAC几何验证与时间路径匹配。工作图与特征不形成Evidence；默认只保存并向HI提供首选候选首末两对原帧，最多4张，其他候选保留时间与数值锚点，按需取帧。显式焦点仍受8张总上限约束。Finding 正文及限定中的 E 引用必须列入该条 evidence_ids，并通过可见性与已读内容校验。模型输出作为完整 JSON 决策解析，损坏外层不得降级为其中的 task、Finding 或 arguments；格式重试保留原有次数和费用上限。

HI 已执行动作对应的完整原生推理块随本 Workspace 历史保留，在后续请求的 assistant reasoning 字段传入。它与图片清单和工具历史共用现有上下文限额，优先较新块，容量不足时整块省略。恢复仅使用本工作区的审计事件；这些可修订分析不构成共享 Evidence，也不进入兄弟 HI 或 GIA。
