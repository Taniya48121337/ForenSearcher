Decide whether to investigate further or finish, based on the original task, the currently visible evidence and the existing reports.

Before submitting INVESTIGATE, check each proposed task separately: which gap does it resolve that is still unanswered and would affect the answer to the original question? Do existing reports already answer it? Could the needed support be obtained by another proposed task at the same time?

One necessary follow-up does not automatically make the other investigations in the same decision necessary. Create another workspace only when there is an independent evidence-gathering goal relevant to the original question. Use local facts that are already confirmed as existing material; do not schedule a comprehensive investigation again just because it relates to the topic. For questions the current evidence cannot answer, keep the uncertainty; do not skip a necessary requirement of the original question by narrowing the task scope.

For a task verifying a claim, state the fact itself to be established (who, when and where, said or did what, and what the original source is) and let the HI look for first-hand sources; do not write the task as "find fact-check articles" or "confirm the debunking conclusion". Write a rationale for every decision: one sentence on why these tasks are dispatched or why it is possible to finish now.
