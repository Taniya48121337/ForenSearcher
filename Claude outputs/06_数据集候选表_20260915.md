# 数据集候选表（2026-09-15）

用途：为第 7 节"新任务快速适应"和第 9 节实验计划选数据集。原则：按五个能力维度扩，每维度训练 1–2 个 + 留出 1 个，总数 10–12 个；每个数据集必须有可执行的核验依据（标注、原始来源、可比对的参考），因为第 8 节的核验器要靠它。

来源：8 月 16 日的旧调研 `docs/01_早期探索_已放弃/ECSO_DATASET_TOOLBOX_LANDSCAPE_20260816.md`（约 80 个数据集，但完全没覆盖地理定位/拍摄时间和非人脸 AI 生成检测两个维度）加 9 月 15 日一轮新检索。"未核实"的项目明确标出，不要当成已确认。

现用六个：TRUE、AVeriTeC、AVerImaTeC（事实核查，文字/图文说法）、VideoSham（视频篡改）、QVHighlights（片段定位）、VCSL（拷贝定位）。主测试：EVID-Bench（锁定）。已下载未用：VidDiffBench。

## 二、按五个能力维度的推荐组合

**(a) Out-of-context / 旧视频新语境。** 训练：GroundLie360（若仓库 dataset 目录可用——含原视频、辟谣视频和 Snopes 证据，是唯一同时具备"视频 + 原源 + 时空 grounding"的真实 OOC 数据）+ AMG（Time/Event Inconsistency 归因与 Snopes 证据，补图像+时间不一致）。留出：FVC（false context / outdated 类别，转帖链给出最早出现关系，可直接测溯源；老数据与 EVID 无重叠）。EVID-Bench 的 contextual fabrication 是主测试，训练用真实核查来源的 GroundLie360/AMG 避免污染；NewsCLIPpings 为合成错配，仅作可选预热。

**(b) 短视频平台假新闻（音频/字幕）。** 训练：FakeSV（中文，抖音/快手，含 ASR/OCR/评论与辟谣视频）+ FakeTT（英文 TikTok，Snopes 溯源）。留出：WildFakeBench（六平台中英混合，10 类归因，可测跨平台/归因泛化；需先邮件拿数据）。两者均需签协议但流程成熟；核验器可用"辟谣视频/Snopes 事件"作证据锚点。

**(c) AI 生成/深伪视频与音频（DETECT 工具）。** 训练（工具校准，不进策略主训练）：MVAD（唯一覆盖 Sora2/Veo3 级同步音视生成、三种模态伪造模式）+ In-the-Wild 音频子集。留出：AIGVDBench 闭源模型测试子集（11 个闭源生成器各 2,000 视频，测 DETECT 对未见生成器的泛化）。旧调研已警告深伪数据会诱导"看 artifact 就判假"，故只用于训练/校准 DETECT 叶子工具和其置信度输出。

**(d) 地理定位/拍摄时间估计。** 训练：CityGuessr68k（视频→层级地点）+ M4FC 的 location verification / image contextualization 子任务。留出：IMAGEO-Bench（精确经纬度，Haversine 指标现成）；若 GTPred 或 AVG 确认公开，优先替换为 GTPred（唯一含拍摄年份估计）。这是旧调研完全缺失的维度；"拍摄时间估计"目前没有可确认公开的视频级数据集，需在论文中明确为空白，只能靠 GTPred（可得性未知）或从 FVC/AMG 的 outdated/TimeInc 样本间接覆盖。

**(e) 多语言（尤其中文）claim。** 训练：MR2（中英多模态谣言，自带反向图搜/网页证据快照，可直接作离线 SEARCH 索引）+ CFEVER（3 万中文 claim + 维基证据，接现有文本核查适配器）。留出：MCFEND（14 家中文核查机构，与 MR2 无重叠）。M4FC/X-Fact 均不含（或无法确认含）中文。

合计 15 个：GroundLie360、AMG、FVC、FakeSV、FakeTT、WildFakeBench、MVAD、In-the-Wild、AIGVDBench、CityGuessr68k、M4FC、IMAGEO-Bench、MR2、CFEVER、MCFEND。若压到 12，去掉 In-the-Wild（并入 MVAD 音频分支）、CFEVER（纯文本，与 TRUE 重叠）、M4FC（无中文、URL 失效）。

## 三、看起来相关但不建议使用

NewsCLIPpings（自动错配，无真实来源，且需另申请 VisualNews）；VERITE（仅 1,000 条且原 URL 大量失效，只能作低优先级图像 OOC 留出）；Factify 2（自动构造标签噪声大，无来源）；FakeVE / FMNV（FMNV 的假视频为 LLM+TTS 合成，非真实传播；只含假样本）；GenVidBench（6.78M 体量过大，生成器偏旧，无音频）；AV-Deepfake1M++（1.46 TB、gated、单说话人实验室场景）；AVFakeBench（未发布）；FaceForensics++ / DFDC / Celeb-DF（换脸年代久远，用 MVAD/AIGVDBench 覆盖更现代）；X-Fact（无法确认含中文）；GeoRC（街景版权 + 仅 500 场景，只作推理链 rubric 参考）；VMH（主观性强，规模/许可不明）；VidDiffBench（与取证无关，仅在需要"成对比较"课程时使用）。

## 四、需人工进一步核实

1. GroundLie360 GitHub `dataset/` 目录内容与许可。
2. FakeSV 精确规模、MR2 / MOCHEG 规模。
3. AVG、GTPred、AVFakeBench 是否真正公开。
4. X-Fact 25 语言清单是否含中文。

## 五、下一步

先不下载。按维度各挑一个训练集，做三件事：读一遍它的标注格式，写一页"适配器说明"（输入怎么变成 GIA 任务、输出怎么算指标、核验器能核什么），估算存储和视频失效率。五份说明写完再决定下载顺序。
