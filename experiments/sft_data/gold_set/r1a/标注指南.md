`verdicts_r1_judged…134runs-6a8cb9f4.jsonl` / `verdicts_units_r1_judged…`）。格式与 r0g2 相同：`items.json`（要看的内容）、
`strata.json`（抽样层与核验器判定，**标注时不要打开**）、`media/`、`标注.html`（双击打开，导出 `labels_<标注人>.json`）。
复算：`python scripts/_gold_eval.py --batch experiments/sft_data/gold_set/r1a --labels labels_<标注人>.json`。

## 怎么抽的（标注人可以知道，但不要据此猜某一条是否被标错）

- `_gold_sample.py --findings 20 --answers 10 --plans 0 --seed 20261018 --oversample-flagged --new-action-quota 8 --answers-balanced
  --round-prefix r1 --only-cases walker_r1_cases.json`
- Finding：r1 全量 738 条 Finding 里核验器标 major/critical 的 26 条，过采样；另留 8 个名额给 r1 新动作的 Finding（E 图片比对结论 2、
  L 图片比对结论 2、C 帧结论 2、C 整段转写概括 2），类内标错的先取。最后 20 条里核验器标错的占多数，**比例不代表总体**。
- 答案：核验器答案层判 positive 5 条、negative 5 条（0.4.0 报告说答案层金标一直没复核过，这批专门补它）。

## Finding：判"所引证据是否支持这条陈述"

`main`：**full**（全部被所引 E 支持）/ **partial**（核心对，但有一处说过头、数字/日期/归因不准、或引了不支持它的 E）/
**none**（核心不被支持或被反驳）/ **cannot_tell**（材料不够判断）。有问题时勾错误类型（unsupported_assertion、wrong_citation、
sloppy_numeric、attribution_drift、scope_overreach…），`span` 抄出有问题的片段，`note` 写一句理由。

r1 新动作的 Finding 要多看一眼：

1. **E / L 图片比对结论**（引了 compare_media 记录 + "A | B | 对齐后的 B" 三栏对照图）：看对照图本身。差异面积 ≤ 2% 写"同一张"、
   ≤ 35% 写"同一张有局部差异（裁切 / 加框 / 贴字）"、更大写"不是同一张"——陈述有没有把"有局部差异"写成"完全相同"，或把
   配准失败、差异很大的写成"同一张"？页面上的图是"页内主图"（og:image 等抽出来的）时，陈述有没有说明是哪一页的哪张图？
2. **L 地点**：陈述说"这页写明拍于 X"时，所引页面正文里真有 X 吗？与参考照片比对的结论（match / no match / cannot tell）有没有
   超出画面能证明的范围？
3. **C 帧结论**（引了 video_structure / get_frames 的帧图）：逐帧看，声明说的那件事（动作 / 物体 / 场景）帧里看得到吗？
   "帧里没看到"是否被写成了"视频里没有"？
4. **C 整段转写概括**：概括是否覆盖了整段（不只第一句），有没有把转写里没有的话写进去？

不要因为"工具原话照抄"就判 full：工具测量值归因给工具是可以的（"compare_media 报告 0.5% 差异"），但若同一条 Finding 引的对照图
显示了明显差异而陈述只字不提，按 partial（scope_overreach / unsupported_assertion）判。r0g2 里 F006 / F009 的这一口径负责人还没定，
遇到同类情况请在 note 里注明"同 r0g2 F006 口径"。

## 答案：判"按所引 Finding / E，答案能不能接受"

`main`：**acceptable** / **minor**（有小问题仍可接受）/ **unacceptable**。看三件事：每句是否有所引 Finding / E 支撑；有没有回答
案卷的每条要求（requirements）；结论（真 / 假 / 无法判定、最早来源与日期、拍摄地）是否与证据一致、有没有说过头。
**不要拿 GT 判**：GT 不在标注页里；答案按证据如实写"无法确定"是可以接受的。
